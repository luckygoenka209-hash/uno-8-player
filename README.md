# UNO 8 Player

A browser-based UNO-style multiplayer game for up to 8 players.

## Run
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run:
   npm install
   npm start
4. Open http://localhost:3000

## Play with friends
For LAN, use your PC's local IP, e.g. http://192.168.1.10:3000.
For internet play, deploy the Node.js app to a host that supports WebSockets.

## Included
- 2–8 players
- Room create/join
- 7-card starting hands
- Real-time turns
- Skip, Reverse, +2, Wild, +4
- Color selection
- UNO button
- Winner detection
- Responsive browser UI

This is an UNO-style implementation and does not include official UNO branding/assets.
